你好，我是 rensongqi。这个站点用来放我的技术笔记，目前的重心是分布式存储，尤其是 Ceph —— 从架构原理、集群部署，到日常运维与性能调优。

写这些东西的原则

  • 可验证：命令、参数、阈值尽量给出处或实测结论，不写"据说"。
  • 可复制：代码片段直接能跑，参数表给出 HDD 与 SSD 两套建议值。
  • 讲清为什么：不只写"这样做"，也写"为什么不能那样做"以及踩过的坑。
  • 图表优先：能用一张图说清的，不写三段文字。

站点

  • 纯静态 HTML + 少量原生 JS，无构建、无框架、无追踪脚本。
  • 文章内所有配图均为内联 SVG，缩放不糊，也便于搜索与复制。
  • 托管在 GitHub Pages。
