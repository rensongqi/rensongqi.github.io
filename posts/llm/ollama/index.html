2026-09-14 · 约 200 字 · 源自 notes-src/llm/ollama/README.md
#LLM#Ollama

运行ollama

docker run -d -v ollama:/root/.ollama -p 11434:11434 --name ollama ollama/ollama

安装llama3.1:8b模型

docker exec -it ollama bash
ollama run llama3.1:8b
